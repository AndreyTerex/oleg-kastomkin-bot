# Запуск бота «Олег Кастомкин»

Бот ведёт сборы на кастомки и скримы на сервере «ПОДГОТОВКА К WORLDS» и болтает в чате как Олег.
Настраивать ничего не нужно — токен бота, ключи нейросетей и свежие данные (сборы, память Олега)
уже внутри архива. Нужен только Docker и включённый компьютер: пока он выключен, бот в Discord оффлайн.

## Главное правило: бот работает только у одного

Токен один на всех. Если бот запущен и у вас, и у владельца, подключения выбивают друг друга
и он начинает отвечать через раз. Поэтому порядок такой:

1. **Владелец выключает своего:** `docker compose down` в папке бота.
2. **Только потом вы запускаете своего** (ниже).

Когда владелец заберёт бота обратно — наоборот: сначала `docker compose down` у вас.

## 1. Поставить Docker Desktop (один раз)

Скачать с [docker.com](https://www.docker.com/products/docker-desktop/), установить, запустить.
Подождать, пока значок кита в трее перестанет мигать и появится надпись «Docker Desktop is running».
При установке на Windows он может попросить перезагрузку — соглашайтесь.

Чтобы бот сам поднимался после перезагрузки компьютера, включите в Docker Desktop:
Settings → General → **Start Docker Desktop when you sign in**.

## 2. Распаковать архив

- **Бот у вас уже был** — распакуйте в ту же папку, где он лежит, **с заменой файлов**.
  Данные в архиве свежее ваших, их тоже нужно заменить.
- **Первый раз** — распакуйте куда угодно, например в `C:\oleg-bot`.

Внутри должна быть папка `oleg-bot` с файлами `bot.py`, `update.bat`, `docker-compose.yml`
и папками `cogs`, `data`.

## 3. Запустить

Дважды щёлкните **`update.bat`** в папке `oleg-bot`. Он сам проверит Docker, скачает готовый образ бота
(или соберёт его, если скачать не вышло), запустит бота вместе с автообновлением и покажет логи.

Дальше бот обновляется сам: рядом с ним работает Watchtower, который раз в 5 минут проверяет новую версию.

На macOS/Linux то же самое — в терминале в папке бота:

```bash
docker compose pull && docker compose up -d
```

## 4. Проверить, что работает

В логах должны появиться строки:

```
Олег болтает через: groq:…, tokenharbor:…, openrouter:…, huggingface:…
Команд синхронизировано для сервера 720627486534139964: 21
Бот в сети: Олег Кастомкин#5758 (серверов: 1)
```

После этого в Discord бот «в сети», команды `/custom`, `/scrim`, `/ping` работают, а Олег отвечает
в чате, если написать «Олег, привет». Окно логов можно закрыть — бот продолжит работать.

## Что может понадобиться дальше

| Задача | Команда в папке бота |
| --- | --- |
| Посмотреть логи | `docker compose logs -f` |
| Перезапустить, если подвис | `docker compose restart` |
| Выключить бота (и автообновление) | `docker compose down` |
| Включить снова | `docker compose up -d` |

**Папку `data` не удалять.** В ней сборы (кто записан, капитаны, составы), настройки каналов
и память Олега. Без неё кнопки на уже опубликованных постах перестанут работать, а Олег всё забудет.

**Архив и `.env` никому не пересылайте.** Внутри токен бота и ключи нейросетей владельца.

## Если что-то не так

| Что видно | Что делать |
| --- | --- |
| `Docker is not running` / `Cannot connect to the Docker daemon` | Запустите Docker Desktop и подождите надписи «running». |
| `Discord отклонил токен` | Токен сброшен — нужен свежий архив от владельца. |
| `session has been invalidated` по кругу | Бот запущен ещё у кого-то — выключите лишний. |
| Бот в сети, но не реагирует на кнопки | `docker compose restart`, потом посмотрите логи. |
| Олег молчит, в логах `Не удалось обратиться к …` или `Лимит …` | Нейросети недоступны из вашей сети или кончился бесплатный лимит. Сборы и команды при этом работают. |
| В логах `Сообщения приходят без текста` | В Developer Portal выключен Message Content Intent — это исправляет владелец. |
